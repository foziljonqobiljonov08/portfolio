# Fozil Portfolio

Professional Vue + Vite portfolio redesign.

## Ishga tushirish PowerShell

```powershell
cd port2
npm install
npm run dev
```

Brauzerda ochiladi:

```text
http://localhost:5173/
```

## Build tekshirish

```powershell
npm run build
npm run preview
```

## Nimalar o'zgartirildi

- Eski sidebar olib tashlandi, premium fixed navbar qo'yildi.
- Hero section professional UI bilan qayta qilindi.
- About, Skills, Projects va Contact sahifalari professional design systemga tushirildi.
- Contact route xatosi tuzatildi.
- Project cardlar tutorial ko'rinishidan real product/dashboard ko'rinishiga o'tkazildi.
- 320px gacha responsive media qo'shildi.
- `node_modules` zip ichidan olib tashlandi.
